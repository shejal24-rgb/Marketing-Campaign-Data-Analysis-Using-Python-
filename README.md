## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on marketing campaign data to understand customer behavior, campaign responses, income patterns, spending scores, and website engagement.

Using Python libraries, the project explores customer characteristics and compares responses across different marketing channels.

> 🎯 **Goal:** Understand customer engagement and discover useful patterns in marketing campaign performance through data analysis and visualization.

## 🎯 Project Objectives

- Analyze customer demographics and income.
- Evaluate marketing campaign responses.
- Compare customer spending scores across campaigns.
- Explore customer website engagement.
- Understand customer behavior through data visualization.
- Identify patterns in campaign performance.

## 📊 Dataset Information

The project uses a fictional sample dataset containing **30 customer records**.

| Column | Description |
|---|---|
| `Customer_ID` | Unique customer ID |
| `Age` | Customer age |
| `Gender` | Customer gender |
| `Income` | Annual income (sample units) |
| `Spending_Score` | Customer spending score |
| `Campaign` | Marketing campaign channel |
| `Response` | Customer campaign response |
| `Website_Visits` | Number of website visits |

**Dataset Note:** This is fictional sample data created for educational and portfolio purposes. It does not represent actual marketing campaign results.

## 📈 Analysis & Visualizations

The project generates six visualizations:

| Visualization | Analysis |
|---|---|
| Campaign Responses | Compares Yes and No responses by campaign |
| Spending Score by Campaign | Compares average spending scores |
| Income Distribution | Explores customer income patterns |
| Age vs Spending Score | Examines age and spending behavior |
| Income by Gender | Compares average income by gender |
| Website Visits vs Spending Score | Explores customer engagement |

## 🔍 Key Analysis Questions

- Which campaign channels have more customer responses?
- How does spending score vary across campaigns?
- What is the distribution of customer income?
- How do age and spending score relate?
- Is website engagement associated with spending scores?
- How do average incomes compare across genders?
